NoiseStorage 日本語

Storage that only ever holds noise.

NoiseStorage is personal, end-to-end encrypted storage you run on your own small server. Your files are encrypted on your Mac or iPhone before they leave it. The server stores chunks of ciphertext and nothing else, and it answers nobody who does not hold a key.

How it works

  1. Encrypt on the device. Every file is split into chunks and encrypted with a fresh random key per version. Names, folders, versions and the trash live in an encrypted index that only your devices can read. All keys descend from a 24-word recovery phrase that never leaves your devices.
  2. Reach the server through a built-in tunnel. The app embeds WireGuard, with QUIC inside it. No VPN profile, no browser login, no open web port. Anyone without a registered key gets no reply at all — the server is invisible to them.
  3. Store noise. The server keeps opaque blobs on a disk. It cannot read, name, group or restore anything. Losing the server means losing ciphertext; losing the phrase means losing the data.

What the server cannot see

File contents

Encrypted before upload. The server never sees a plaintext byte.

Names and folders

Kept in the encrypted index, together with versions and the trash.

Who you are

Devices authenticate with keys. There are no accounts, passwords or e-mail addresses.

That it exists

One UDP port that stays silent without a key. Nothing to scan, nothing to log in to.

What it does not hide

  • How much you store and when: the number and sizes of blobs, and the timing of transfers.
  • Your server's address: your network sees the IP and port you talk to, and the hosting provider knows who rents it.
  • A lost recovery phrase is a lost archive. There is no reset, by design.

Run it yourself

The server is a single static binary for Linux. A small VPS with a large disk is enough — the author runs it on a 1 TB storage VPS with one CPU core and 1 GB of memory. It opens exactly one UDP port; everything else stays closed. Devices are added with a one-time code or a QR code shown by a device that is already set up.

Status

A personal project, in daily use by its author. The Mac and iPhone apps are not distributed yet and the source code is not published yet. This page will say when that changes.
